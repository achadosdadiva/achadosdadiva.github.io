# grupo-ofertas-beleza

Página de entrada do grupo de ofertas de beleza no WhatsApp, publicada pelo GitHub Pages. É o destino
dos anúncios.

Para alterar, edite o bloco de configuração no fim do `index.html`:

- `GROUP_INVITE`: link de convite do grupo. Troque aqui se o WhatsApp revogar o link ou se um grupo novo for aberto.
- `META_PIXEL_ID`: ID do Pixel da Meta. O clique em "Entrar no grupo" dispara o evento `Lead`, que é o evento
  que a campanha otimiza.

Cada push na `main` republica a página em alguns minutos.
